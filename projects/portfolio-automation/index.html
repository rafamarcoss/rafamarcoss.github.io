Google Search Console

Index state, through the official API.

01
Submit sitemap

Sends the public XML sitemap for the exact URL-prefix property.

02
Inspect sitemap URLs

Extracts each URL, then reads canonical, crawl, robots and index state.

03
Monitor carefully

Uses a Service Account, GitHub Secrets and sequential quota-aware requests.

The system does not automate the Search Console UI and does not misuse Google's Indexing API. It relies on the official Search Console APIs.

Implementación

Small scripts, explicit responsibilities.

Authentication, sitemap submission and inspection are independent Node.js modules. The workflow only submits when manually requested; daily runs inspect status without modifying the site.

Decisiones de ingeniería

Automation with limits on purpose.

01 / API

Official APIs over browser automation

No scraping, UI automation or Indexing API for normal pages.

02 / SECRETS

Credentials outside Git

The Service Account JSON exists only as a GitHub Secret or temporary environment variable.

03 / QUOTA

Quota-aware requests

URL inspections are sequential with a pause between calls.

04 / FAILURE

Correct failure semantics

Not indexed is reported, not treated as a broken workflow. Auth and API failures stop the job.

05 / SEO

Static-first SEO architecture

Articles and AI Signal editions have static URLs, canonical metadata, JSON-LD and sitemap entries.

06 / OPS

Observable workflows

RafaOps records health, incidents and run evidence around the publishing system.
