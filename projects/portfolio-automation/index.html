Project · production systems

Automated Portfolio Infrastructure

Static publishing, operational monitoring and search visibility for rafaelmarcos.tech.

GitHub Actions · Node.js · Search Console APIState: infrastructure in place

Overview

A portfolio as an operating system.

The problem was not building another static website: an edition needs to be generated, deployed, monitored and discoverable in search without leaving invisible failures behind.

Problem

Publishing, monitoring and maintaining SEO by hand did not scale as content and integrations grew.

Build

Independent scripts for authentication, sitemap submission, inspection and monitoring, each with an explicit responsibility.

Result

The site publishes static content, supervises workflows and audits index state without automating private interfaces.

Architecture

Four responsibilities, one verifiable path.

PublishGitHub Actionsscheduled and manual orchestration
ContentStatic pagesAI Signal and articles
ObserveRafaOpshealth checks and incidents
SearchGSC APIsitemap and URL inspection

Engineering decisions

Automation with intentional limits.

Official APIs

No scraping, UI automation or inappropriate use of the Indexing API for normal pages.

Secrets and quota

The Service Account stays out of Git; inspections are sequential and quota-aware.

Failure semantics

Unindexed is reported; authentication and API failures stop the job.
