Automated Portfolio Infrastructure

Publicación estática, monitorización operativa y visibilidad de búsqueda para rafaelmarcos.tech.

GitHub Actions · Node.js · Search Console APIEstado: infrastructure in place

Overview

Un portfolio como sistema operativo.

El problema no era construir otra web estática: una edición debe generarse, desplegarse, vigilarse y poder descubrirse en búsqueda sin dejar fallos invisibles.

Problem

Publicar, vigilar y mantener el SEO a mano no era sostenible cuando el contenido y las integraciones crecían.

Build

Scripts independientes para autenticación, sitemap, inspección y monitorización; cada uno con una responsabilidad explícita.

Result

La web publica contenido estático, supervisa workflows y audita el estado de índice sin automatizar interfaces privadas.

Architecture

Cuatro responsabilidades, una ruta verificable.

PublishGitHub Actionsorquestación programada y manual
ContentStatic pagesAI Signal y artículos ES/EN
ObserveRafaOpshealth checks e incidentes
SearchGSC APIsitemap e inspección URL

Engineering decisions

Automatización con límites intencionados.

Official APIs

Sin scraping, automatización de interfaz ni uso indebido de la Indexing API para páginas normales.

Secrets and quota

La Service Account vive fuera de Git; las inspecciones son secuenciales y conscientes de cuota.

Failure semantics

No indexada se informa; los fallos de autenticación o API sí detienen el job.
