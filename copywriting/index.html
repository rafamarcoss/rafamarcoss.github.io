FAQ

Questions before we start.

What topics do you write about?

SaaS, AI, automation, APIs, CRM workflows, technical operations and adjacent B2B software topics where the product context can be researched properly.

Do you handle keyword research?

Yes. The work begins with the search intent and topic fit, then uses keyword research as evidence for the page angle and structure rather than as a density target.

Can you write for technical audiences?

Yes. The process includes documentation and source review, so the content can explain architecture, integrations, technical trade-offs and implementation context without flattening the details.

Can you work from product documentation or an existing SEO brief?

Yes. Documentation, internal subject-matter input and an existing brief are useful starting points. I use them to identify what needs verification, clarification or a stronger editorial angle.

Do you use AI to write content?

AI can support research and iteration, but it does not replace source review, technical judgment or the final editorial decision. The goal is useful, accurate content, not automated volume.
