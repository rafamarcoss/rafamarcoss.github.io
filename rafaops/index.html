RafaOps

An agentic control plane for observing automations, collecting evidence and supervising bounded recovery.

Current state loading…GitHub Actions · Node.js · DeepSeekOperation: monitored, supervised recovery

Overview

Automation does not end when it publishes.

RafaOps exists so workflows do not fail silently. It reads health checks and execution evidence, separates incidents from expected states, and prepares recovery for human review.

Problem

A publish or workflow can partially complete, become blocked or produce an invalid output without anyone seeing it.

Architecture

Workflows leave state in GitHub Actions; the monitor collects checks, incidents and runs in a static ledger.

Result

Every round creates operational evidence: service state, executions and recovery decisions.

What I learned

Limits are part of the architecture.

An unindexed URL is not the same as a broken workflow. Recovery must be bounded, credentials kept out of Git, and evidence available before deciding to intervene.
